# Caesar Cipher Encrypt-Decryption GUI App

A simple C++ GUI-based application using Qt that allows users to **encrypt** and **decrypt** `.txt` files using the **Caesar Cipher** technique.


## Features

- GUI-based file selection (with "Choose Your File" button).
- Caesar Cipher encryption and decryption.
- Displays success message with the location of the saved file.
- Easy to use and beginner-friendly.


## How It Works

- **Encryption**: Each alphabetic character is shifted by a fixed number of positions (default shift: 3).
- **Decryption**: Reverses the encryption to restore the original content.

# Technologies Used

- **C++**
- **Qt (Widgets module)**


## Getting Started

### 1. Install Qt (if not already installed)
### 2. Use this commands in the terminal.
- qmake encrypt_gui.pro
- make
- ./encrypt_gui

**That's all.**
